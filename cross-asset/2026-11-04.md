## ⚠️ Deviations from the skill spec

- **Window end derived from the data, not chosen.** `--window-end auto` resolved the last *completed* session to **2026-11-03** (128 aligned sessions, 127 log-return observations). The 2026-11-04 session is in progress and is **excluded** from the published matrix; the excluded session's effect is quantified in the partial-session section below (max pair move 0.0194 on UUP–^VIX — no conclusion changes).
- **No live quote feed was used.** The intraday column is derived from the snapshot's own price series (last bar vs the one before it, labelled with the bar date), not from a quote feed, so no feed's retrieval timestamp can be mistaken for the session date.
- **Prior-week comparison window** is the matched-length window rolled back seven days: **2026-04-27 → 2026-10-27** (128 sessions / 127 obs) — no date arithmetic was done by hand.
- **`series.json` / `mats_partial.json` are not emitted by `correlation_matrix.py`.** A thin wrapper reusing the helper's *own* fetch, alignment and SQL-building functions produced them, so every table in this artifact remains script-generated; the partial matrix is still computed server-side (DuckDB `corr()` via the MCP bridge), not by hand.
- **Basis: `adjclose`** (split/dividend-adjusted closes), consistent with the prior snapshot. `^VIX` was **included** — Yahoo carries it, shibui does not.
- **Universe unchanged** (8 proxies: SPY, QQQ, IWM, TLT, GLD, UUP, EEM, ^VIX). No additions or removals this run.
- **Independent cross-check**: the matrix was recomputed from shibui's own raw closes over the same dates. It validates the *price series*, not the published basis (raw close ≠ adjusted close for distributing ETFs).
