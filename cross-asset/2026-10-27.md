## Deviations from the skill spec (read first)

- **The skill's required tool was not available.** `mcp__financekit__correlation_matrix` is not bound in this Cloud session — nor are the `mcp__tradingview_advanced__*` or `mcp__yahoo_finance__*` tools the cron prompt lists. `tool_search` for quote/chart/correlation tools returned 0 hits, and `mcode-tools connector tools` returns only `matrix__*` (multimodal) and `email_workbench__*` connectors — no market-data connector exists to call. The skill's "compute only via `correlation_matrix`, do not compute manually" hard rule is therefore unsatisfiable in this environment.
- **Fallback used:** Yahoo Finance Chart API (`query2.finance.yahoo.com/v8/finance/chart/{{symbol}}?range=1y&interval=1d`), one call per proxy, short `User-Agent: Mozilla/5.0` header, TLS verified via `--cacert /etc/ssl/certs/agent-identity/sandbox-gateway-ca.crt` (no `-k`). All **8/8 calls returned HTTP 200**. Pearson correlations were then computed locally on daily log returns. The run stopped at this fallback and did **not** chain to any deeper MCP.
- **`range=1y` instead of `range=6mo`.** The spec fixes the *window* at 6 months, not the fetch length. Fetching 1 year of bars was necessary to build the equal-length comparison window (ending 2026-10-16) on the same 6-month length, so both windows are directly comparable. The published matrix is still a strict 6-month window.
- **The headline matrix excludes the in-progress session.** The market was open at run time (2026-10-27 10:11 EDT), so the `2026-10-27` bar is a partial session, not a daily close. Mixing a half-session return into a daily-return series would bias the covariance estimates, so the headline uses completed sessions only (through Monday 2026-10-26). The cost of that choice was measured rather than assumed: including the partial bar moves the returns matrix by at most **0.0041** and the levels matrix by at most **0.0247** (see *Sensitivity to the in-progress session*).
- **The spec's week-over-week delta is now non-degenerate, unlike the prior run.** The prior snapshot (`2026-10-26.md`) was itself a window ending 2026-10-23, so its WoW delta was 0.00 by construction and was reported as a freshness fact. One session (Monday 2026-10-26) has since closed, so today's WoW delta is a genuine market observation: **+0.0066 maximum across all 28 pairs**.
- **Return-vs-level choice.** The spec does not say whether the matrix is built on daily *returns* or on *price levels*. Returns are the standard basis for a correlation matrix and are used as the primary table; the levels matrix is in the appendix because it produces materially different headline pairs (SPY–TLT is +0.33 on returns but −0.69 on levels).
- **Week-rolled comparison methodology changed from the prior file.** The 2026-10-26 artifact rolled the window forward from a *fixed start* (2026-04-24), which changes the window length as it rolls (122 vs 127 sessions) and mixes a length change into the delta. This run uses **equal-length** windows (127 sessions each, ending 2026-10-16 vs 2026-10-26), so the roll isolates trading-time change rather than sample-size change. The two week-rolled tables are therefore not directly comparable to each other; the spec's WoW table is, and is the primary stability measure.
- **The skill is designed as a Sunday 16:30 ET weekly snapshot, but this cron fires intraday.** The artifact is published on a Tuesday with the market open, which is why the partial session and the equal-length roll are both reported explicitly.
- Correlation is **regime context only** — not causation, not a forecast.

## TL;DR

The correlation structure is **essentially unchanged**: 8 of 28 pairs remain strongly related (|r| > 0.7), and the largest week-over-week move across all 28 pairs is **0.0066**, which is rounding-scale rather than a structural break. Stocks and long bonds are still **positively** correlated (SPY–TLT +0.33, IWM–TLT +0.49), so the stock/bond hedge has still not been working over this sample, and growth remains barely coupled to duration (QQQ–TLT +0.19, the only pair in the matrix below the 0.20 near-orthogonal threshold). The USD is still the dominant cross-asset signal — **negatively** correlated with both equities (SPY–UUP -0.38) and gold (GLD–UUP -0.59) — and is one of only two proxies that rose over the window (UUP +5.68%) while gold collapsed (GLD -14.44%). Implied vol still tracks equities inversely (SPY–^VIX -0.78), and growth and EM remain a single crowded bloc (QQQ–EEM +0.88).

The live tape reinforces the risk-on-with-easing-vol reading: in Monday's completed session SPY rose +0.71% and QQQ +1.11% while ^VIX fell 5.45%, and in today's partial session (≈10:11) SPY +0.11%, QQQ +0.38%, EEM +0.68% and GLD +0.66% are all higher with ^VIX down 1.96% to 18.03. The one persistent wrinkle is **EEM**, which fell 0.31% on Monday even as everything else rallied.
