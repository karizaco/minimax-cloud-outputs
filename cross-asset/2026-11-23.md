## ⚠️ Deviations from the skill spec

- **The in-progress session was excluded.** This fire is intraday (10:00 ET), so 2026-11-23 was still trading. `window_end` was derived from the fetched data (`--window-end auto`) as the last **completed** session, **2026-11-20** (Friday); the 2026-11-23 bar is quantified separately in the excluded-partial-session section and changes no pair by more than the amount stated there.
- **The week-over-week comparison is a matched-length window roll, not a literal seven-day shift.** The prior window is 2026-05-13 → 2026-11-13 (129 sessions), the same length as the current 2026-05-20 → 2026-11-20 (129 sessions), so the two matrices are comparable session-for-session. No date arithmetic was done by hand.
- **`^VIX` is included.** All 8 proxies returned data on every one of the 8 Yahoo series (8/8 HTTP 200, no nulls), so no column was dropped. `^VIX` is excluded from the session calendar used to build the common date set (it prints overnight and can carry a bar the ETFs lack), which is why the return observations span consecutive common sessions only.
- **Basis: `adjclose`** (split/dividend-adjusted closes) for both the current and the prior window, so the delta is basis-consistent.
- **Prior-window source health is inherited from the same fetch.** The prior window is computed from the same aligned series already pulled for the current window; it carries no separate HTTP source row.

**Stocks and bonds have decoupled — and that is the week's real story.** SPY–TLT fell from **+0.24** to **+0.11** across the matched-length window roll, and every TLT correlation moved the same way (IWM–TLT +0.42→+0.29, TLT–EEM +0.19→+0.08, TLT–GLD +0.26→+0.15, QQQ–TLT +0.12→+0.02). **Everything else held its structure.** Equity-internal correlations are unchanged (SPY–QQQ +0.93, QQQ–EEM +0.90, SPY–IWM +0.83, SPY–EEM +0.80), VIX remains the cleanest single risk gauge in the set at **-0.88** versus SPY, and the dollar still opposes gold (**GLD–UUP -0.53**) with SPY–UUP at **-0.24** — the USD–gold rotation trade is still live. The best diversifier in the universe is **QQQ–TLT +0.02**; nothing in the set is actually uncorrelated to everything else except TLT.

**No regime shift, but the bond block is close.** The largest week-over-week pair move is **0.1352** against a **0.20** threshold — inside it, so `regime_shift: no`, yet two-thirds of that headroom was consumed in one week by the TLT block alone. Correlation is regime context only, not causation.
