- **Adjustment basis:** `adjclose` (Yahoo split/dividend-adjusted closes), held consistent with the prior week's snapshot so the week-over-week delta compares like with like.

- **Comparison window:** the prior-week window is MATCHED-LENGTH by construction (`--prior-window`): 2026-05-04 → 2026-11-02, 127 sessions / 126 return observations, same `adjclose` basis.
- **VIX:** `^VIX` is not in shibui and carries sessions the ETFs lack; it is fetched from Yahoo and mapped to the `VIX` identifier for the SQL. Returns are computed over the COMMON date set of all 8 proxies, so no pair spans a different interval.
- **MCP availability probe:** `catalog_ok total=135 finance_tools=0` — no financial MCP is registered on this runtime, and the bridge answered normally (`bridge_ok packs=tradier,fmp,market-recap`). Not a finding, and not an error.
- **Duplicate-window check:** performed by `tools/check_cross_asset_artifact.py` against the `cross-asset/` listing in `karizaco/minimax-cloud-outputs` (ref `main`) before push.
