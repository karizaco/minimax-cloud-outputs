## Deviations from the skill spec (read first)

- **The skill's required tool was not available.** `mcp__financekit__correlation_matrix` is not bound in this Cloud session — neither are the `mcp__tradingview_advanced__*` or `mcp__yahoo_finance__*` tools the cron prompt lists. `mcode-tools connector tools` returns only `matrix__*` and `email_workbench__*` connectors, and a direct MCP invoke of a Yahoo-Finance tool name fails with `Unknown tool_name`.
- **Fallback used:** Yahoo Finance Chart API (`query1.finance.yahoo.com/v8/finance/chart/{symbol}?range=6mo&interval=1d`), one call per proxy, with a browser User-Agent (without a UA the endpoint returns HTTP 429). Pearson correlations were then computed locally on daily log returns. This violates the skill's "compute only via `correlation_matrix`, do not compute manually" hard rule; the rule was not satisfiable in this environment, so the run continued on the fallback and stopped there rather than chaining to another MCP.
- **Return-vs-level choice:** the spec does not say whether the matrix is built on daily *returns* or on *price levels*. Returns are the standard basis for a correlation matrix and are used as the primary table below; the levels matrix is included in the appendix for transparency because it produces materially different headline pairs (e.g. SPY–TLT is +0.33 on returns but -0.69 on levels).
- **No week-over-week delta is possible.** No prior snapshot exists — `/workspace/cross-asset/` did not exist before this run, and `karizaco/minimax-cloud-outputs` has no `cross-asset/` path (GitHub contents API returns 404). The spec's WoW step was substituted with an in-window early-half → recent-half comparison, which is a **different measurement** and is labelled `REGIME_DRIFT`, not `REGIME_SHIFT`. The first true WoW delta will be possible next week (2026-10-18's snapshot does not exist either; the baseline will be this file).
- Correlation is **regime context only** — not causation, not a forecast.

## TL;DR

Stocks and long bonds are **positively** correlated over this window (SPY–TLT +0.33, IWM–TLT +0.48), and growth is barely coupled to duration at all (QQQ–TLT +0.19) — the classic stock/bond hedge has not been working in this six-month sample. The USD is the strongest single cross-asset signal: it is **negatively** correlated with both equities (SPY–UUP -0.38) and gold (GLD–UUP -0.59), and it is the one proxy that rose over the window (+5.39%) while gold collapsed (-15.38%). Growth and EM remain a single crowded bloc (QQQ–EEM +0.88), and implied vol still tracks equities inversely as expected (SPY–^VIX -0.78).
