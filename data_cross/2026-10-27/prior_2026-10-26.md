## Deviations from the skill spec (read first)

- **The skill's required tool was not available.** `mcp__financekit__correlation_matrix` is not bound in this Cloud session — neither are the `mcp__tradingview_advanced__*` or `mcp__yahoo_finance__*` tools the cron prompt lists. `mcode-tools connector tools` returns only `matrix__*` (multimodal) and `email_workbench__*` connectors, and a `tool_search` for quote/chart/correlation tools returns zero hits. The skill's "compute only via `correlation_matrix`, do not compute manually" hard rule is therefore unsatisfiable in this environment.
- **Fallback used:** Yahoo Finance Chart API (`query2.finance.yahoo.com/v8/finance/chart/{symbol}?range=1y&interval=1d`), one call per proxy, short `User-Agent: Mozilla/5.0` header, verified TLS via `--cacert /etc/ssl/certs/agent-identity/sandbox-gateway-ca.crt` (no `-k`). All 8 calls returned HTTP 200. Pearson correlations were then computed locally on daily log returns. The run stopped at this fallback and did **not** chain to any deeper MCP.
- **`range=1y` instead of `range=6mo`.** The spec fixes the *window* at 6 months, not the fetch length. Fetching 1 year of bars was necessary to build the week-rolled comparison window (ending 2026-10-16) on the same 6-month length, so both windows are directly comparable. The published matrix is still a strict 6-month window.
- **The headline matrix excludes the in-progress session.** The market was open at run time (10:07 ET), so the `2026-10-26` bar is a partial session, not a daily close. Mixing a half-session return into a daily-return series would bias the covariance estimates, so the headline uses completed sessions only (through Friday 2026-10-23). The cost of that choice was measured rather than assumed: including the partial bar moves the returns matrix by at most **0.01** and the levels matrix by at most **0.05** (see *Sensitivity to the in-progress session*).
- **The spec's "week-over-week delta" is degenerate this week and is reported as such.** The prior snapshot (`2026-10-25`) is also a window ending **2026-10-23**, because no session has closed since. The published WoW delta is therefore **0.00 across all 28 pairs** — that is a *data-freshness* fact, not a stability finding. The informative regime measure is the **week-rolled window** (same 6-month length, ending 2026-10-16 vs ending 2026-10-23), reported below.
- **Return-vs-level choice.** The spec does not say whether the matrix is built on daily *returns* or on *price levels*. Returns are the standard basis for a correlation matrix and are used as the primary table; the levels matrix is in the appendix because it produces materially different headline pairs (SPY–TLT is +0.33 on returns but −0.69 on levels).
- Correlation is **regime context only** — not causation, not a forecast.

## TL;DR

The correlation structure is **unchanged and stable**: the week-rolled comparison moves no pair by more than 0.08, and 28 of 28 pairs reproduce last week's published matrix to within rounding. Stocks and long bonds remain **positively** correlated (SPY–TLT +0.33, IWM–TLT +0.48), meaning the stock/bond hedge has still not been working over this sample, and growth is barely coupled to duration at all (QQQ–TLT +0.19, the only pair in the matrix below the 0.20 near-orthogonal threshold). The USD remains the dominant cross-asset signal — **negatively** correlated with both equities (SPY–UUP −0.38) and gold (GLD–UUP −0.59) — and is the one proxy that rose over the window (+5.39%) while gold collapsed (−15.38%). Implied vol still tracks equities inversely (SPY–^VIX −0.78), and growth and EM remain a single crowded bloc (QQQ–EEM +0.88).

The one live development is in today's partial session: **^VIX is down 4.68% to 18.54 and EEM is down 1.08%** at ~10:07 ET, while SPY, QQQ, IWM, TLT and UUP are all modestly higher. Vol is easing while EM sells off, which is the opposite of a risk-off impulse.
