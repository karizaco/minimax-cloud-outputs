## 9. Method notes

- Every `curl` for the shared scripts went through the **contents API first** (authoritative, not
  CDN-cached), then `raw.githubusercontent`, then jsDelivr — all four fetched clean on the first URL.
- Every status in this report was **measured**, not inferred. A refused or unreachable probe is
  recorded as `auth_required` / `probe_failed:<reason>`, never as "no tools exist" or "no MCPs".
- The pack inventory was enumerated by **union of six discovery queries**, then each pack was
  measured directly — because discovery ranks, it never enumerates.
- The TradingView pull used the repo's validated client, so its completeness assertion is the
  client's own (`rows == totalCount`, disjoint pages), not a hand-rolled check.
