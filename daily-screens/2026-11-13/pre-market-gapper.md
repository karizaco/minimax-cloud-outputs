## Method, source health & caveats

| Source | Endpoint / query | Status | Role |
|---|---|---|---|
| Universe resolver | `premarket_universe.py --fire-date 2026-11-13` | ok | resolved the expected prior session **2026-11-12** from the market's own session history, matched the published Focus list, picked the close column **by date**, confirmed every reference close on an independent source |
| Nasdaq extended-trading tape | `api.nasdaq.com/api/quote/<SYM>/extended-trading` | ok | **source of record** for the published gap, the executed print and pre-market volume; pulled until the cached vintage stops changing (min 2, max 4) |
| Nasdaq `/info` | `api.nasdaq.com/api/quote/<SYM>/info` | ok | the live quote (`quote_price`, `quote_gap_pct`) and bid/ask — published separately from the tape |
| Cboe delayed-quote CDN | `cdn.cboe.com/api/global/delayed_quotes/quotes/<SYM>.json` | ok | independent price cross-check, not subject to the Nasdaq cache |
| TradingView america scanner | `scanner.tradingview.com/america/scan` | ok | reference close and pre-market cross-check, the sector and 30-day average volume, the index/sector proxies for the driver classification, and the market ladder |
| web_search | — | ok | the catalysts for the market ladder |
| issuer press releases / SEC 8-K | — | ok | NPCE, LFTO, DGXX, YSS, CADL |
| MarketBeat / Yahoo Finance / MT Newswires / CNBC | — | ok | MOD, CBRS, NMAX, HAWK |

- **Margin against the trigger:** the widest absolute gap on any source is **3.50%** against a 4.00% trigger — a 1.14x margin, so the flag decision is immune to which cached vintage a source returns.
- **Denominator:** every gap uses the **2026-11-12 settled close** — the prior sweep's own `focus.csv` close column, chosen BY DATE, with `screen_close_resolved` (the screen's T+1 data date) rejected as a denominator.
- **Tape freshness:** the newest print was 15-81 min behind the wall clock at the time of the pull. A stable cache returns the SAME vintage however many times it is asked, so the burst of pulls protects against a ROTATING cache but not against an old one — which is why `tape_lag_min` is published on every row.
- **Tape waves:** wave 1 at 08:37:05 ET (12 names); wave 2 at 08:39:07 ET (3 names). A wave that is spread across the run is what produces the divergence record; the re-pull wave only re-pulls the decision-relevant names (|gap| >= 2% or a stale tape), because a name below the near-miss band cannot change the flag decision.
- **Driver classification:** the gap is compared with the index proxy (SPY +0.35%), the sector proxy and bitcoin (-2.11% overnight from 11-12 16:00 ET) on the SAME TradingView snapshot as the name, so the two numbers are comparable. The published gap stays the Nasdaq tape's.
- **Known Nasdaq defects checked on every fire** (`/info` `secondaryData.lastSalePrice` not always the settled close, the field flipping mid-session, `primaryData.lastSalePrice` being a trivial-size print or the ask, the bridge's `market_state: pre` serving the prior regular close, and the TradingView `premarket_volume` undercount) — the published gap is the tape's last executed print in every row and the live quote is a separate column.
- **What could not be verified:** the TradingView `earnings_release_date` field is a *candidate* catalyst, not a confirmed one, and it is sometimes stale for a name whose move is not an earnings move. Where no same-session catalyst was confirmed on the wire or in an issuer release, this artifact says so rather than inventing one.
- The Focus universe is the 2026-11-11 sweep (12 names) because cron #09's 2026-11-12 sweep never published; every reference close is the 2026-11-12 settled close taken from the independent sources only (TradingView + Cboe + session-exact Nasdaq history all agreeing).
- All pre-market gaps come from the consolidated tape's last EXECUTED print; the live quote is published separately as quote_price / quote_gap_pct.
- Catalysts were confirmed on the wire or in an issuer release; a TradingView earnings_release_date was treated as a candidate only.
