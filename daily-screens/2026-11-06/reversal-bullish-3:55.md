## Method, source health & caveats

- **Session alignment — proof this scan is for today:** TV implied previous close vs shibui's latest settled close: **12/12 agree** (100.0%) → mode **LIVE**. The scanner's session is pinned before any gate is applied.
- **The signal is TODAY's live candle, not yesterday's.** The routine proves this at runtime (alignment above); it no longer resolves the screen date as "shibui's latest settled date", which was a one-session lag.
- **The candle is the SETTLED 2026-11-06 session bar, re-pulled after the 16:00 ET bell.** Entry prices are the official closes (IRM 106.52, IT 190.10), confirmed against Nasdaq's settled print (IRM $106.49, IT $189.94), and volume is the full session — so `vol_vs_30d_avg_pct` is a same-basis ratio against the 30-day mean, not a partial-day reading.
- **The candidate set changed between the 15:55 ET pre-close read and this settled read.** At ~15:55 ET the screen produced 4 mechanical passers — IT, AMTM, EQH, CRBG — on partial bars; at the settled close AMTM and CRBG fail the small-body gate (body 0.361 and 0.388 vs the 0.30 limit), EQH fails the hammer test (lower shadow 1.15 < 2× upper 0.68), and **IRM qualifies only on the closed bar** (DCR 0.776, volume 167% of the 30-day average). This artifact is the settled read: a name that only qualifies after the closing print is a name whose bar changed shape at the bell.
- **ADR(20) is computed over the 20 SETTLED sessions before today**, not over a window that includes the incomplete live bar.
- **`vol_vs_30d_avg_pct` compares the FULL settled session volume with the full-day 30-session mean**, so the ratio is same-basis. `capitulation = CAPITULATION` at ≥ 150% of that mean, `LOW_VOLUME` below it.
- **The market-cap gate uses TradingView's live `market_cap_basic`**, not shibui's `valuation` table, which stores stale rows per symbol and can admit a phantom name if the cap filter is applied before the latest-row pick.
- **"Prefer higher priced stocks" is a ranking preference, not a filter** — the published gate is `c >= 5`; names are ordered by DCR then ADR.
- **`stop_class` is published on every row, not buried in prose.** `NOISE_BREACH` = the published stop sits inside the signal bar's own range, so the bar already traded through it; `CAPPED` = the 2.5% cap bound the stop while it still sits at/below the bar low; `STRUCTURAL` = the published stop is the structural level. `stop_vs_bar_low_pct` is signed: negative = the stop is below the bar low.
- **Bonde's discretionary step is mandatory**: the mechanical screen returns candidates, then the review reduces them to **1–3 ideas** ("no catalyst, no trade", "the reversal bar has to jump off the chart"). Every promoted idea carries a named catalyst and an invalidation test.
