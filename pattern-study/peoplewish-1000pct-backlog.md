## Methodology

- **Universe:** all symbols in shibui.stock_quotes with at least 1,260 trading days in the trailing 10-year window.
- **Trigger:** `(current_close / 10y_min_close) - 1 >= 10.0` (1000%+ from trough).
- **Min close filter:** `min_close_10y >= $0.50`.
- **Security type:** newly-tagged names are restricted to `type = 'Common Stock'`; leveraged ETNs and ETFs inflate a 10-year return mechanically and are excluded from the tag list (the raw scan still records them in the run JSON).
- **Chart-shape tags** (on the most recent 60d / 10d window): `coil` — close within 15% of 60d high AND contraction (10d range / 60d range) < 0.85; `VCP` — contraction < 0.65; `breakout` — close / high_60d >= 0.95; `EP` — close > 50% above the YTD low; `big_day` — last session moved > 5%.
- **The scan is PAGED, never capped.** shibui's ceiling is 200 rows PER QUERY, so a query that returns exactly 200 rows is truncated, not complete. Page until the collected rows equal `rows_passing`.
- **The ledger rows are frozen** at the values they carried when first tagged — it is a discovery ledger, not a quote sheet. The live re-score below carries this week's tags.
