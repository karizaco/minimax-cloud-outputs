- **Driver** is read from the catalyst the 08:30 brief already sourced - this file searches for no news. `has_news = no` in the morning CSV is `NONE`, and so is a name whose cluster carried the news but whose own catalyst was not sourced.

## 5. Source health

- **One pull.** Every number in this file and in the companion CSV comes from a single pull of the TradingView `america` scanner at 10:06:17. Both screens were pulled with `range:[0,1000]` and `len(rows) == totalCount` held on each (489/489 gainers, 203/203 decliners), so `screen_complete: true` and the band counts are exact.
- **The scanner's `close` column is the LIVE regular-session price, not the prior close.** It disagreed with the morning brief on 581 of the 747 common names — that wholesale move IS the live session the gate reads, and it is why the front matter carries `market_open_at_pull: true`. The published prior close for every name is the DERIVED one (from the pre-market print), never the scanner's `close`.
- **`prior_close` is DERIVED**, never taken from the screener's `close` column: `round(premarket_close / (1 + premarket_change_pct / 100), 4)`, computed from the values this CSV publishes (4 dp price, 2 dp change) so every row reproduces its own prior close.
- **Market cap**: the morning brief's reconciled cap (529 names); scanner (143 names); stockanalysis_shares x close (17 names). The cap published for a name is the RECONCILED one where the pull could corroborate it, and the scanner's own `market_cap_basic` otherwise.
- **The Driver is read from the morning brief's OWN sourced catalysts**, per name - `has_news = no` is `NONE`, and so is a name whose cluster carried the news but whose own catalyst was not sourced. `NONE` is a finding: 20 of the 25 headline names have no sourced catalyst.
- **The morning brief's CSV is a published-name subset, not the whole band.** It holds 914 rows (702 of them in the +/-3% band) against a band the brief counted at 702.0 names, so band-level fade and entrant counts cannot be derived from it: a name absent from the CSV was never published, which is not the same as having faded out of the band. **The comparison base used here is the 702 published band names**, and the fade count (189) and the entrant count (17) are stated against that base. The 162 live-band names the morning CSV never carried are reported as unclassified rather than counted as entrants.
- **No catalyst was searched for in this run.** The Driver column carries the catalyst the 08:30 brief already sourced and labels it with the fixed vocabulary. A name with no sourced catalyst is `NONE`.
- **6 rows carry a null value from the scanner** (MDRN, TREO, IAM, ZOAR, APXC, GLU/PB) and their cells are published **empty, never 0**: a missing average volume is not a zero volume, and a zero would make `pct_of_adv` a fabricated number.
