## 5. Source health

- **One pull.** Every number in this file and in the companion CSV comes from a single pull of the TradingView `america` scanner at 09:21:52. Both screens were pulled with `range:[0,1000]` and `len(rows) == totalCount` held on each (221/221 gainers, 486/486 decliners), so `screen_complete: true` and the band counts are exact.
- **The regular session had not opened at the pull.** The scanner's `close` column is the last completed regular session's close, and the companion CSV's `live_close`, `live_change_pct` and `live_volume` columns are **blank, never 0**.
- **`prior_close` is DERIVED**, never taken from the screener's `close` column: `round(premarket_close / (1 + premarket_change_pct / 100), 4)`, computed from the values this CSV publishes (4 dp price, 2 dp change) so every row reproduces its own prior close.
- **Market cap**: the morning brief's reconciled cap (583 names); scanner (109 names); stockanalysis_shares x close (14 names). The cap published for a name is the RECONCILED one where the pull could corroborate it, and the scanner's own `market_cap_basic` otherwise.
- **The setup slot is a rung-1 slot.** The ladder takes the first rung that is satisfiable: anchored plus one of the five classes (rung 1), then anchored plus any class whose gap is still holding at Hold 80 or better (rung 2). The slot is a LONG on a gap-up - the trigger is the pre-market high, the level that must break for the gap to extend - so a rung-1 class sitting on a gap-down name whose gap has already given back its range is not a setup.
- **The Driver is read from the morning brief's OWN sourced catalysts**, per name - `has_news = no` is `NONE`, and so is a name whose cluster carried the news but whose own catalyst was not sourced. `NONE` is a finding: 13 of the 25 headline names have no sourced catalyst.
- **The morning brief's CSV is a published-name subset, not the whole band.** It holds 905 rows (678 of them in the +/-3% band) against a band the brief counted at 678 names, so band-level fade and entrant counts cannot be derived from it: a name absent from the CSV was never published, which is not the same as having faded out of the band. **The comparison base used here is the 678 published band names**, and the fade count (121) and the entrant count (27) are stated against that base. The 123 live-band names the morning CSV never carried are reported as unclassified rather than counted as entrants.
- **No catalyst was searched for in this run.** The Driver column carries the catalyst the 08:30 brief already sourced and labels it with the fixed vocabulary. A name with no sourced catalyst is `NONE`.
- **3 rows carry a null value from the scanner** (ANT, TREO, EVRL) and their cells are published **empty, never 0**: a missing average volume is not a zero volume, and a zero would make `pct_of_adv` a fabricated number.
