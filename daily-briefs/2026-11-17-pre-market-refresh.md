## 5. Source health

- **One pull.** Every number in this file and in the companion CSV comes from a single pull of the TradingView `america` scanner at 21:24:08. Both screens were pulled with `range:[0,1000]` and `len(rows) == totalCount` held on each (286/286 gainers, 271/271 decliners), so `screen_complete: true` and the band counts are exact.
- **`prior_close` is DERIVED**, never taken from the screener's `close` column: `round(premarket_close / (1 + premarket_change_pct / 100), 4)`, computed from the values this CSV publishes (4 dp price, 2 dp change) so every row reproduces its own prior close.
- **Market cap**: the morning brief's reconciled cap (392 names); scanner (145 names); stockanalysis_shares x close (19 names). The cap published for a name is the RECONCILED one where the pull could corroborate it, and the scanner's own `market_cap_basic` otherwise.
- **The Driver is read from the morning brief's OWN sourced catalysts**, per name - `has_news = no` is `NONE`, and so is a name whose cluster carried the news but whose own catalyst was not sourced. `NONE` is a finding: 20 of the 25 headline names have no sourced catalyst.
- **The morning brief's CSV is a published-name subset, not the whole band.** It holds 774 rows (480 of them in the +/-3% band) against a band the brief counted at 479.0 names, so band-level fade and entrant counts cannot be derived from it: a name absent from the CSV was never published, which is not the same as having faded out of the band. **The comparison base used here is the 480 published band names**, and the fade count (123) and the entrant count (35) are stated against that base. The 165 live-band names the morning CSV never carried are reported as unclassified rather than counted as entrants.
- **No catalyst was searched for in this run.** The Driver column carries the catalyst the 08:30 brief already sourced and labels it with the fixed vocabulary. A name with no sourced catalyst is `NONE`.
- **1 row carries a null value from the scanner** (MDRN) and their cells are published **empty, never 0**: a missing average volume is not a zero volume, and a zero would make `pct_of_adv` a fabricated number.
